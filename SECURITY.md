# Security Policy

## Supported Versions

Only the latest active development versions of the Software are supported for security updates.

| Version | Supported |
| ------- | --------- |
| Main branch / Active Dev | ✅ Yes |
| < 1.0.0 | ❌ No |

## Reporting a Vulnerability

If you identify a security vulnerability in this application, please report it responsibly by contacting the security team directly. Do **not** open a public GitHub issue, as this software is proprietary and confidential.

Please send security reports to:
- **Email**: `security@d4rkwolf.com`

Please include the following details in your report:
- A description of the vulnerability and its potential impact.
- Detailed step-by-step instructions or a proof-of-concept (PoC) to reproduce the issue.
- Details of the environment where it was tested.

## Our Commitment

We take security seriously and will acknowledge receipt of your report within 48 hours. We will provide updates on the remediation timeline as we investigate the issue.
